AM브리핑 — 배포용 PWA 패키지
================================
이 폴더는 국내주식 아침 브리핑 PWA "AM브리핑"의 소스예요.
(index.html, manifest.json, sw.js, icons/ 4개 파일 세트)

배포 현황 (2026.08.27 기준)
----------------------------
- 실제 서비스 주소: https://am-briefing-pwa.vercel.app/
- 이 GitHub 저장소(pitr1000-blip/am-briefing-pwa)가 Vercel 프로젝트와
  Git 연동되어 있어요. main 브랜치에 커밋을 push하면 Vercel이 자동으로
  감지해서 몇 초~몇 분 안에 새 버전을 배포해요. 따로 Netlify Drop이나
  vercel CLI, 수동 업로드 같은 과정은 더 이상 필요 없어요.

수정하는 방법
--------------
- 급하게 한 군데만 고칠 때: GitHub 저장소에서 해당 파일(예: index.html)을
  열어 연필(✏️) 아이콘으로 바로 편집 → "Commit changes"로 main에 커밋
  → Vercel이 알아서 재배포
- 통째로 갈아끼울 때: 이 폴더 전체를 저장소 루트에 다시 업로드
  ("Add file" → "Upload files")해도 됩니다

매일 아침 데이터 자동 갱신
--------------------------
- index.html 안의 코스피/코스닥 시세, 뉴스, 관심종목 시세는 매일 바뀌는
  데이터라 주기적으로 갱신이 필요해요.
- Claude의 자동화 루틴이 평일 아침마다 코스피/코스닥/뉴스/관심종목
  데이터를 조회해서 index.html의 데이터 부분만 갈아끼우고 main 브랜치에
  자동으로 push하도록 설정 중이에요. (레이아웃·CSS·JS 로직은 건드리지
  않고 데이터만 교체)
- 지금 담긴 시세·뉴스는 2026.08.27 자 초기 업로드 스냅샷이에요. 자동
  갱신 루틴이 정상 작동하기 시작하면 이 문구도 함께 업데이트할게요.

관심종목(워치리스트)
--------------------
- 관심종목은 브라우저(기기)별 로컬 저장(localStorage)이에요. 로그인
  계정 동기화는 아직 없어서, 기기를 바꾸면 새로 담아야 해요.

홈 화면에 앱처럼 설치하기
--------------------------
- Android(Chrome): 메뉴 → "홈 화면에 추가"
- iOS(Safari): 공유 버튼 → "홈 화면에 추가"
누르면 아이콘이 생기고 앱처럼 전체 화면으로 실행돼요.

카카오톡/슬랙 등에 링크 공유 시 미리보기 카드
----------------------------------------------
- index.html <head>에 og:title / og:description / og:image(og-image.png,
  1200x630) 태그가 들어있어요. 배포된 주소를 카톡·슬랙·트위터 등에
  붙여넣으면 앱 소개 카드가 자동으로 떠요.
- og:image, twitter:image, og:url은 실제 배포 주소
  (https://am-briefing-pwa.vercel.app/) 기준 절대경로로 이미 넣어뒀어요.
  도메인을 나중에 바꾸면 이 3곳도 같이 바꿔주세요.
- 카톡 공유 미리보기가 바로 안 뜨면, 카카오 디버거
  (https://developers.kakao.com/tool/debugger/sharing) 에 배포 주소를
  넣고 "초기화" 하면 캐시가 갱신돼요.
